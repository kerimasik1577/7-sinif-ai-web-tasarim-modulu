## 📌 Proje Hakkında

**7-sinif-ai-web-tasarim-modulu**, Ortaokul 7. sınıf Bilişim Teknolojileri ve Yazılım dersi öğrencilerine **İstem Mühendisliği (Prompt Engineering)** ve **Web Arayüz Tasarımı** becerilerini yaparak-yaşayarak kazandırmak amacıyla geliştirilmiş web tabanlı etkileşimli bir öğretim materyalidir.

Pasif konu anlatımı yerine **"Önce Etkileşim, Sonra Öz-Özet"** ilkesini benimseyen platform; 80 dakikalık (2 ders saati) akışı **Robert Gagne’nin 9 Öğretim Etkinliği Modeli** ve **TPAB (TKPACK)** çerçevesiyle bütünleştirir.

## ✨ Öne Çıkan Özellikler

* **✍️ Serbest Prompt Analizörü ve Canlı HTML Üretici:** Öğrencilerin kendi cümleleriyle yazdıkları istemleri **Rol, Konu, Renk/Tema ve Bileşen** kriterlerine göre gerçek zamanlı puanlar; Gemini AI API (ve çevrimdışı akıllı yedek motor) ile çalışan gerçek bir web sayfası oluşturup tarayıcı içinde canlı sunar.
* **🎮 Oyunlaştırma (Gamification):** Dinamik XP puan sistemi, adım ilerleme çubuğu, Web Audio API ile tarayıcı içi sentezlenen başarı/hata ses efektleri ve *AI Web Mimarı* başarı rozeti.
* **📊 BÖTE Öğrenme Analitiği Paneli:** Öğrencinin toplam XP puanını, tamamladığı adım sayısını, rozet durumunu ve quiz doğruluk oranını anlık raporlayan değerlendirme ekranı.
* **⚡ Sıfır Bağımlılık (Single-File SPA):** Kurulum gerektirmeyen tek dosyalık (`index.html`) mimarisi ile tüm masaüstü ve mobil tarayıcılarda doğrudan çalışır.

---

## 🛠️ Kullanılan Teknolojiler

* **Yapı & Arayüz:** HTML5, Tailwind CSS, FontAwesome, Google Fonts (*Fredoka & Nunito*)
* **Etkileşim & Mantık:** Vanilla JavaScript (ES6+), HTML5 Drag & Drop API, Web Audio API, Sandboxed `iframe` (`srcdoc`)
* **Yapay Zeka Entegrasyonu:** Google Gemini API (`gemini-3-flash-preview`) + Çevrimdışı Akıllı Şablon Motoru
